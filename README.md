# Formulario 510 — Declaración de Importación Simplificada

Aplicación de escritorio para diligenciar el Formulario 510 de la DIAN Colombia.

## Descarga del .exe

1. Ir a la pestaña **Actions** del repositorio
2. Clic en el último workflow completado
3. Bajar hasta **Artifacts**
4. Descargar **Formulario510-Windows**

## Uso

1. Abrir `Formulario510.exe` con doble clic
2. Llenar el formulario manualmente, **o**
3. Usar la plantilla `PlantillaFormulario510.xlsx` y presionar **📥 Cargar desde Excel**
4. Presionar **📄 Generar PDF** para exportar la declaración

## Archivos incluidos

- `main.py` — código fuente de la aplicación
- `PlantillaFormulario510.xlsx` — plantilla Excel para carga automática
